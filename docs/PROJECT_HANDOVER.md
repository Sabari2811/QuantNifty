# Objective

Before adding any more features, the entire UI architecture will be reviewed and aligned with the backend architecture.

The objective is to ensure:

- Every backend component has a UI representation.
- Every UI component has one primary owner.
- Duplicate information is eliminated.
- Missing backend capabilities are exposed.
- Future AI modules have dedicated UI locations.

No implementation should begin until Milestone 0.5 planning is complete.

# Engineering Rules

The project follows milestone-based development.

Every milestone follows this workflow:

1. Architecture Review
2. Backend Review
3. UI Review
4. Implementation
5. Testing
6. Screenshot Validation
7. Code Review
8. Git Commit
9. Merge
10. Git Tag

No feature jumping.

No parallel implementation.

One milestone must be fully completed before the next begins.
